# Password Reset Policy

## Standard Reset

Users can reset passwords through the identity portal. The reset flow requires MFA confirmation and a compliant new password.

## Account Lockout

After repeated failed login or MFA attempts, the account can be temporarily locked. Ask the user to wait 15 minutes before retrying unless there is a suspected security incident.

## Security Checks

If the user reports unexpected MFA prompts, suspicious login notifications, or a password reset they did not request, escalate to Security immediately.
