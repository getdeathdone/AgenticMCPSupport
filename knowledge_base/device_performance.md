# Device Performance Checklist

## Symptoms

Users report slow laptops, high CPU usage, application freezes, or poor performance after updates.

## First Checks

Check pending reboot status, endpoint health, disk space, encryption status, and recent security scans.

## User Steps

Ask the user to reboot, close unused applications, connect to power, and confirm whether the issue started after an operating system or security update.

## Escalation

Escalate to Endpoint Support when device health is warning or critical, disk space is low, or performance remains poor after reboot.
